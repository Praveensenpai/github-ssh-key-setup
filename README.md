# 🔑 github-ssh-key-setup

Automated Ed25519 SSH key generator and GitHub connection setup utility.

---

## ✨ Features

- 🔑 **Ed25519 Key Generation**: Generates modern Ed25519 SSH keypairs if missing.
- ⚙️ **SSH Agent Auto-load**: Starts `ssh-agent` and adds identity.
- 📋 **Guided Instructions**: Displays public key and step-by-step GitHub deployment guide.

---
